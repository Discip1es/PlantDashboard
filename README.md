# PlantDashboard

Система мониторинга параметров окружающей среды для активного роста растений. Веб-приложение имитирует дашборд в стиле Grafana, визуализирует данные с датчиков (температура, влажность воздуха и почвы, освещение, уровень CO2, давление) в реальном времени. Данные генерируются сервером с учётом суточных циклов, случайных трендов и эмуляции полива.


## Стек технологий

- **Backend**: .NET 6/7/8, ASP.NET Core MVC, SignalR
- **Frontend**: Bootstrap 5 (CDN), Chart.js (CDN), Font Awesome
- **Тестирование**: xUnit, Moq, FluentAssertions
- **Библиотеки**: Microsoft.AspNetCore.SignalR


## Требования

- [.NET SDK](https://dotnet.microsoft.com/download) 6.0 или выше
- Любая современная ОС (Windows, Linux, macOS)
- Браузер с поддержкой WebSockets


## Установка и запуск

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/your-repo/PlantDashboard.git
   cd PlantDashboard
   ```

2. Восстановить зависимости:

   ```bash
   dotnet restore
   ```

3. Собрать проект:

   ```bash
   dotnet build
   ```

4. Запустить приложение:

   ```bash
   dotnet run --project src/PlantDashboard/PlantDashboard.csproj
   ```

5. Открыть в браузере адрес, указанный в консоли (обычно `https://localhost:5001` или `http://localhost:5000`).


## Конфигурация

Настройки симуляции датчиков задаются в классе `PlantRoomConfig` (оптимальные диапазоны для растений). По умолчанию:

| Параметр          | Min | Optimal | Max |
|-------------------|-----|---------|-----|
| Температура       | 18  | 24      | 30  |
| Влажность воздуха | 50  | 65      | 80  |
| Влажность почвы   | 40  | 65      | 85  |

Для изменения отредактируйте значения в конструкторе `SensorSimulatorService` или внедрите собственную конфигурацию.

**SignalR Hub** доступен по адресу `/sensorHub`. Клиент подключается автоматически и получает обновления каждые 2 секунды.


## Использование

После запуска отображается дашборд, состоящий из:

- Шести карточек с текущими показателями и цветовым индикатором здоровья (зелёный – оптимально, жёлтый – внимание, красный – критично).
- Трёх графиков:
  - Температура и влажность воздуха (линейный график, две оси Y)
  - Влажность почвы и уровень CO2
  - Освещение (klx) и давление (hPa)

Все графики обновляются в реальном времени через WebSocket (SignalR). Сервер генерирует новые значения каждые 2 секунды, имитируя:

- Дневной цикл освещения (пик в полдень, минимум ночью)
- Зависимость влажности воздуха от температуры
- Медленное снижение влажности почвы с вероятностью полива
- Колебания CO2 в зависимости от времени суток (активность людей)
- Случайные тренды температуры и влажности

- `TimeProvider` – абстракция времени для тестирования


## Тестирование

Проект содержит модульные тесты (xUnit + Moq). Для запуска:

```bash
dotnet test tests/PlantDashboard.Tests/PlantDashboard.Tests.csproj
```

Тесты покрывают:

- Модели данных (свойства, значения по умолчанию)
- SignalR Hub (добавление/удаление из групп)
- Сервис симуляции:
  - Генерация показаний в допустимых диапазонах
  - Влияние времени суток на освещение
  - Обратная связь между температурой и влажностью
  - Устойчивость к исключениям
- Контроллер Dashboard (возврат View с ViewBag)

Для добавления новых тестов используйте `Mock<ITimeProvider>` для управления временем и `Mock<IHubContext<SensorHub>>` для проверки вызовов SignalR.
